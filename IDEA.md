# MathLab — философия и архитектура

Сайт: https://21usual7.github.io/MathLab/ (обновляется сам после push в `main`, через 1-2 минуты).
Локально: нужен любой статический сервер (ES-модули не грузятся с `file://`):
`python3 -m http.server` в папке проекта → http://localhost:8000

## Зачем

Студенты, у которых математика «сломалась» в 10-11 классе. Им не хватает не задач и не формул, а **понимания**: что такое производная на самом деле, откуда берётся $e$, почему поверхность $z = x^2 - y^2$ — это седло. Пробел в одном месте делает непонятным всё, что на нём стоит.

MathLab — **платформа для понимания**: место, где любую идею можно увидеть, потрогать, повернуть в 3D, сравнить с соседними — и так закрыть пробел.

## Принципы

1. **Понимание важнее упражнений.** Задачи — способ проверить себя, а не центр продукта. Центр — момент «а, вот оно что».
2. **Одна идея — много взглядов.** Формула, 2D-график, 3D-вид, числа, анимация показывают *одно и то же*, связаны между собой и окрашены одинаково: синий $f$ в формуле — это синяя кривая на графике.
3. **Всё живое.** Любое число в формуле можно сделать параметром и покрутить; любой параметр можно запустить ▶ и посмотреть, как меняется картина.
4. **Рассказ, а не справочник.** Тема — это последовательность шагов (как ролик 3Blue1Brown), где сцена плавно переходит из состояния в состояние. Но в любой момент можно остановиться и экспериментировать самому.
5. **Свобода экспериментировать.** Lab — чистый холст: сколько угодно функций, поверхностей, кривых, точек, параметров, 2D и 3D.
6. **Карта пробелов.** Темы связаны: у каждой есть «что нужно знать до» и «куда это ведёт». Если непонятно — можно шагнуть назад, к причине.
7. **Красота — часть понимания.** Аккуратная типографика, формулы как в хорошей книге, спокойная тёмная палитра, плавное движение. Посредственный вид = посредственное доверие.

## Части платформы

- **Lab** (`#lab`) — свободная лаборатория. Список выражений слева, вид справа (2D / 3D / оба).
  Понимает: `y = sin(a x)`, `z = x^2 - y^2`, `(cos(t), sin(t))`, `(cos(t), sin(t), t/5)`, точки `(1, 2)`, параметры `a = 1`,
  вертикальные прямые `x = a`, свои функции `f(x) = x^2` и их использование `y = f(x - h) + k`, `y = f'(x)`, `f''`,
  ограничения `y = sqrt(x) {0 <= x <= 4}` и диапазон кривой `(cos(t), sin(t)) {0 <= t <= T}` (концы могут быть параметрами).
  Незнакомая буква (кроме x, y, z, t, e, pi) автоматически становится параметром со слайдером и кнопкой ▶.
  Наведение (на телефоне — касание) на кривую показывает точку с координатами, нули, вершины/впадины и пересечения.
  Кнопка «f′» у функции добавляет строку с её производной. Справка «What can I type?» — под списком.
  **Экранная клавиатура** (кнопка ⌨ у поля ввода; работает и в заданиях тем): формулы можно набирать мышью или пальцем.
  Две вкладки — «123» (цифры, действия, x, y, a, b, степень, корень, скобки, π, e) и «f(x)» (sin, cos, tg, arcsin, ln, log,
  f(x), f′, неравенства, {…}); курсор встаёт внутрь скобок; ←, →, ⌫, ↵. Фокус из поля не уходит; страница уступает
  клавиатуре место снизу; на телефоне системная клавиатура не выскакивает поверх (inputmode="none").
- **Темы** (`#topic/<id>/<шаг>`) — шаги как слайды: слева панель (~31 % ширины, 360–500 px) с одним шагом — текст, живые
  формулы сцены и слайдеры прямо под текстом, вопрос/задание, «Назад / Далее»; сверху точки прогресса (задания — оранжевые,
  решённые — зелёные); стрелки клавиатуры листают. Справа — сцена на всю оставшуюся площадь. На телефоне сцена сверху,
  кнопки прилипают к низу. Каждый шаг задаёт состояние сцены (параметры, видимые объекты, вид, камеру); переход анимируется.
  Шаг хранится в адресе. Кнопка «Open in Lab» (в углу сцены) переносит текущую сцену в Lab.
  Масштаб 2D-окна темы подстраивается под высоту сцены (окно задано для ~760 px), чтобы на мониторе графики не были мелкими.
  В шаге могут быть: «Try» (что потрогать), **«Predict, then check»** — вопрос с вариантами; ответ показывается на сцене только после попытки (`check.reveal`), и **подсказка** «если непонятно» (`hint`), раскрывается по клику.
  В конце темы — блок **«Попробуйте сами»**: задания, которые строят на живой сцене (`task`). Виды: `drag` (перетащить точку/вершину
  в нужное место) и `formula` (прочитать формулу по графику). Проверка без ИИ (`js/core/check.js`): формулы сравниваются
  подстановкой чисел, поэтому засчитывается любая равносильная запись (`f(x − 3)`, раскрытые скобки). При ошибке:
  сначала типичные ошибки задания (`mistakes` — свои объяснения), иначе автоматическая диагностика — график ученика
  сдвинут / растянут / сжат / перевёрнут относительно нужного, на сколько и почему. Ссылка «Повторить: шаг N» ведёт назад
  к причине; после двух попыток можно открыть ответ.
- **Карта** (главная) — два раздела, как в школе. **Алгебра и начала анализа**: Функции → Пределы → Производные → Интегралы → Несколько переменных.
  **Геометрия** (стереометрия): Прямые и плоскости → Углы и расстояния → Тела и объёмы. Ссылки в шапке `#algebra`, `#geometry`
  ведут к своему разделу. Реализованные темы активны, запланированные видны, чтобы было понятно, куда всё ведёт.

## Модель контента

```
Тема = {
  id, track, title {en, ru}, summary {en, ru},
  prereqs: [id],  next: [id],          // карта пробелов
  scene: { objects, params, view, camera, window },   // общая сцена темы
  steps: [{ title, text {en, ru}, try, hint, check: { q, options: [{ text, ok }], explain, reveal(scene, stage) },
           task: { kind: 'drag' | 'formula', target | answer, mistakes: [{ params | formula, text, back }], hints, right, back },
           state: { params, show, view, camera, window, controls }, enter(scene, stage) }],
}
Объект сцены = { id, expr | custom draw, color, label, dim (бледный «до»), legend (показывать в подписи) }
```
Тема — это **данные плюс, при необходимости, небольшие «custom»-объекты** (например, секущая, плоскость сечения). Движок общий для Lab и тем.

## Архитектура (без сборки, ES-модули)

```
index.html              оболочка, importmap для three.js
css/style.css           дизайн-токены, типографика, раскладка
js/main.js              роутер
js/core/expr.js         разбор выражений (math.js), классификация, компиляция, чистый TeX-принтер
js/core/numeric.js      численные методы (производная, интеграл, корни, экстремумы)
js/core/check.js        проверка ответов без ИИ: равенство формул числами, диагностика сдвиг / растяжение / переворот
js/core/geom.js         стереометрия без рисования: векторы, многогранники с именами вершин, плоскость через 3 точки, сечения
js/core/scene.js        сцена: объекты + параметры + подписчики
js/core/anim.js         плавные переходы и проигрывание параметров
js/core/palette.js      палитра (одна для графиков, формул и интерфейса)
js/core/i18n.js         язык пояснений (en / ru)
js/views/plot2d.js      2D-вид (canvas): перемещение, масштаб, адаптивная сетка, ручки, подписи-формулы, линии уровня
js/views/plot3d.js      3D-вид (three.js): поверхности, кривые, точки, плоскости, оси, вращение;
                        многогранники и отрезки как в учебнике — невидимое пунктиром, пересчёт при повороте камеры
js/views/draw.js        как объекты сцены выглядят в 2D и в 3D (функция в 3D — на полу, поверхность в 2D — линии уровня)
js/views/explore.js     чтение графика указателем: координаты, нули, экстремумы, пересечения (Lab и темы)
js/ui/stage.js          сцена в режимах 2D / 3D / 2D + 3D
js/ui/params.js         слайдер параметра с кнопкой ▶
js/ui/tex.js            KaTeX с цветовыми макросами \blue{…}, \yellow{…}
js/ui/exprlist.js       список выражений Lab
js/ui/keypad.js         экранная математическая клавиатура для всех полей с data-keypad
js/ui/task.js           задания в темах: ввод, проверка, объяснение ошибки, «показать ответ»
js/pages/home.js        главная и карта тем
js/pages/lab.js         Lab
js/pages/topic.js       плеер темы
js/topics/*.js          темы (данные)
tests/*.test.js         тесты движка: npm install && npm test (node --test; math.js ставится только для тестов)
```
Библиотеки с CDN: math.js 12.4.2 (разбор и символьная производная), KaTeX 0.16.9 (формулы), three.js 0.160.0 (3D), шрифты Inter и Fraunces.

## Язык

Интерфейс — английский. Пояснения в темах — **русский или английский** (переключатель RU / EN в шапке, выбор запоминается). Формулы общие.

  В темах — вопросы «предскажи, потом проверь» и подсказки; в Lab — кнопка производной и справка. Тесты движка.
- **Тема «Предел»**: дырка 0/0, подход с двух сторон, $\frac{\sin x}{x}$, коридор ε–δ, скачок и $\sin\frac1x$ (предела нет),
  $(1 + \frac1x)^x \to e$. Движок: разрывы-скачки (`sign`, `floor`) не соединяются вертикалью, быстрые колебания
  рисуются сплошной полосой; строгие неравенства в `{0 < x}` сохраняются.
- **Тема «Откуда берётся e»**: сложные проценты (лесенка → $e^x$), наклон $a^x$ против высоты, $e^x$ — своя производная, $\ln x$.
  Lab: переключатель **Tangent** (касательная и наклон под указателем), точки в школьной записи `(1; 2)`, `A(1; 2)`.
- **Темы как слайды** (панель шага слева, сцена справа, прогресс точками, шаг в адресе) и **экранная клавиатура** для формул.
- **Задания «Попробуйте сами»** с проверкой и объяснением ошибок (без ИИ); первые 5 — в теме «Сдвиги и растяжения».
  Ввод понимает функции без скобок: `sin x`, `sin 2x`, `ln x`, `sinx`.
- **Задания в теме «Производная»**: найти точку с наклоном 2 по сетке (ловушка — наклон ½), найти дно впадины $f$
  только по графику $f'$ (ловушки — холм и вершина самой $f'$), записать $g'(x)$ для $g = x^2$ по числам наклона.
  В `drag`-заданиях: несколько правильных ответов (`target: [...]`) и подсказка, зависящая от положения точки (`hints.a = a => …`).
- **Задания в теме «Предел»**: найти дырку $\frac{x^2 - x - 2}{x - 2}$ (ловушки — дырка на оси, ноль числителя, $h(0)$),
  подобрать окно $\delta$ для коридора $\varepsilon = 0.1$ (подходит любое достаточно малое; вышедшее из коридора — красным),
  поставить прямую на высоту предела $\frac{2x + 1}{x - 1}$ при $x \to \infty$ (ловушки — $-1$, $0$, $1$).
- **Задания в теме «Откуда берётся e»**: формула лесенки при 4 начислениях в год $1.25^{4x}$ (ловушки — $1.25^x$, $2^x$, $e^x$,
  $(1 + \frac{x}{4})^4$, простые проценты), точка на $e^x$ с наклоном 3 (наклон = высота → $\ln 3$), формула $3e^x$ по свойству
  «наклон = высота» (ловушка — $e^x + 2$: через ту же точку, но наклоны другие). Диагностика находит растяжение с любым множителем.
- **Геометрия**: карта разделена на «Алгебру» и «Геометрию»; движок многогранников (`geom.js`, невидимые рёбра пунктиром),
  тема «Сечения куба» (плоскость через 3 точки, два правила построения, от треугольника к шестиугольнику, диагональное сечение).

## Риски

- **Объём.** Тема уровня 3Blue1Brown — это дни работы. Лучше 5 отличных тем, чем 30 посредственных.
- **Производительность 3D** на слабых телефонах: ограничивать сетку поверхностей, перерисовывать только при изменениях.
- **Точность.** Числа на сцене должны совпадать с математикой; движок проверяется тестами (`expr`, численные методы).
